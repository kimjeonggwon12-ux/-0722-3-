# 어린 왕자 설명형 쇼츠 - 내레이션 버전

## 📺 영상 특징
- **설명형 구성**: 퀴즈가 아닌 이야기 전개식 내레이션
- **어린왕자 풍 일러스트**: 손그림 스타일의 행성, 왕자, 여우, 장미 등
- **감성 배경음악**: 피아노 같은 차분한 음악
- **책 속 장면**: 오프닝 → 저자 → 여행 → 여우 → 장미 → 메시지 구성

## 📝 6가지 장면 (총 60초)

| 시간 | 장면 | 내용 |
|------|------|------|
| 0-8초 | **오프닝** | 책 소개 |
| 8-18초 | **저자** | 생-텍쉬페리 (조종사, 1943년 비행기 사고) |
| 18-28초 | **여행과 만남** | 6개 행성, 다양한 인물들의 욕망/집착 |
| 28-38초 | **여우와의 만남** | "네가 길들인 것에는 책임이 있다" |
| 38-48초 | **장미** | 평범하지만 소중한 존재의 의미 |
| 48-58초 | **핵심 메시지** | "중요한 것은 눈에 보이지 않는다" |
| 58-60초 | **아웃로** | 책 읽도록 권유 |

## 🎬 내레이션 넣는 법

### 방법 1: 캡컷(CapCut) — 가장 쉬움
1. 모바일에서 캡컷 앱 열기
2. 영상 업로드: `어린왕자_설명형쇼츠.mp4`
3. **텍스트** → **음성** 탭에서:
   - `내레이션_대본.txt` 내용을 각 시간대별로 복사 붙여넣기
   - 또는 **녹음** 버튼으로 직접 목소리 녹음
4. 내보내기

### 방법 2: 직접 녹음
1. 스마트폰 보이스 메모 앱으로 대본을 읽으면서 녹음
2. 캡컷에서 영상 선택 후 오디오 추가
3. 동기화

## 📁 파일 목록
- `어린왕자_설명형쇼츠.mp4` (10MB) — 무음 영상 (내레이션 없음)
- `내레이션_대본.txt` — 읽기 스크립트 (총 약 90초)
- `make_narrative.py` — 재생성 스크립트

## 🎨 비주얼 요소
✓ 우주 배경 (별들이 깜빡거림)
✓ 6개의 손그림 스타일 행성
✓ 왕자 일러스트 (간단한 모양)
✓ 여우 일러스트 (움직이는 애니메이션)
✓ 장미 (점진적으로 커짐)
✓ 빛 효과와 부드러운 전환
