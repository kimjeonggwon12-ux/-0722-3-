# 어린 왕자 테마 1분 상식 쇼츠 — 프리미엄 에디션

"어린 왕자" 책에 얽힌 놀라운 이야기와 인생 교훈을 60초 동안 풀어내는 유튜브 쇼츠입니다.

## 특징
- **고급 비주얼**: 우아한 그래디언트, 파티클 이펙트, 부드러운 애니메이션
- **따뜻한 배경음악**: 감성적인 하모니, 섬세한 퍼커션
- **심화된 내용**: 단순 상식이 아닌 문학적·인생적 의미

## 9개 섹션 (각 6초)

| # | 주제 | 질문 | 정답 |
|---|---|---|---|
| 1 | 📚 책의 기원 | 어린 왕자는 누가 왜 썼나? | 생-텍쉬페리 (조종사 작가) |
| 2 | 📚 판매 기적 | 가장 많이 번역된 책? | 어린 왕자 (500개 언어) |
| 3 | 🌍 상징의 의미 | 왕자가 만난 7개 행성? | 인간의 7가지 욕망 |
| 4 | 🌹 장미의 의미 | 왕자의 장미가 특별한 이유? | 사랑과 책임의 상징 |
| 5 | 🇫🇷 숨겨진 배경 | 저자 생-텍쉬페리의 고향? | 프랑스 아일 지방 |
| 6 | 💭 유명 명대사 | 가장 유명한 문구? | 눈에 보이지 않는 본질 |
| 7 | 🎨 삽화 작가 | 그림은 누가 그렸나? | 저자 본인 (손그림) |
| 8 | 🌟 현대 영향력 | 왕자의 메시지는? | 중요한 건 마음 |
| 9 | ✨ 인생 교훈 | 가장 큰 배움? | 사랑할 것을 놓지 말기 |

## 마무리 (2초)
> "중요한 것은 눈에 보이지 않는다"
> 
> 사랑, 책임, 그리고 순수함을 잃지 말기

## 파일
- `어린왕자_놀라운이야기.mp4` — 완성 영상 (60초)
- `내레이션.srt` — 자막 및 목소리 녹음 대본
- `make_video_premium.py` — 재생성 스크립트

## 업로드 팁
**유튜브 제목:**
```
어린 왕자의 비밀 | 모르던 놀라운 이야기 9가지 1분 완독 #shorts
```

**설명:**
```
책을 한 번도 읽지 않았다면 꼭 봐야 할 영상!
어린 왕자의 기원, 상징, 영향, 그리고 인생 교훈.
생-텍쉬페리가 조종사 경험에서 영감을 얻어 만든 이 작품,
당신도 모르던 놀라운 사실들이 있을 거예요.

#어린왕자 #책 #명언 #인생교훈 #문학
```

## 목소리 넣기
**캡컷에서:**
1. 영상 불러오기
2. 텍스트 → 음성 선택
3. 각 구간의 대사를 읽거나 TTS로 생성
4. 내보내기
